# lu-emacs

Поддержка языка программирования **lu-lang** в GNU Emacs и Doom Emacs.
lu-lang — учебный язык на русском языке, интерпретируемый поверх Python.

## Возможности

- **Подсветка синтаксиса** (font-lock): ключевые слова, команды, константы,
  числа, строки, символы, комментарии (`#`, `//`, `/// … ///`), операторы
  и встроенная функция `длина`.
- **Автоматические отступы**: после строки, открывающей блок
  (`процедура`, `если`, `иначе`, `пока`, `для`, `повтори`), Enter даёт
  отступ в 4 пробела; ввод слов `конец` и `иначе` выравнивает строку влево.
- **Сворачивание блоков** (hideshow): от открывающей конструкции до `конец`.
- **Автодополнение**: ключевые слова и символы файла — переменные
  (`запомнить`), параметры процедур, счётчики циклов, имена процедур.
- **Сниппеты** (yasnippet) для логических блоков и типовых команд.

## Требования

- GNU Emacs 29 или новее.

## Установка в Doom Emacs

Добавьте локальный пакет в `~/.config/doom/packages.el`:

```elisp
(package! lu-lang-mode
  :recipe (:local-repo "~/Develop/lu-lang/lu-emacs"))
```

В `~/.config/doom/config.el` подключите пакет и сниппеты:

```elisp
(use-package lu-lang-mode
  :defer t
  :mode ("\\.lu\\'" . lu-lang-mode)
  :config
  (add-to-list 'yas-snippet-dirs "~/Develop/lu-lang/lu-emacs/snippets")
  (yas-reload-all))
```

Затем выполните `doom sync` в терминале и перезапустите Emacs.

## Установка без Doom (простой init.el)

```elisp
(add-to-list 'load-path "~/Develop/lu-lang/lu-emacs")
(add-to-list 'auto-mode-alist '("\\.lu\\'" . lu-lang-mode))
(require 'lu-lang-mode)
```

## Параметры

| Переменная             | По умолчанию | Назначение                  |
|------------------------|--------------|-----------------------------|
| `lu-lang-indent-offset` | 4            | Ширина отступа вложенных блоков |

## Сниппеты

| Клавиша        | Что вставляет                            |
|----------------|------------------------------------------|
| `если`         | Условный оператор                        |
| `еслииначе`    | Условный оператор с веткой `иначе`      |
| `для`          | Цикл со счётчиком                        |
| `пока`         | Цикл с условием                          |
| `повтори`      | Цикл повторений                          |
| `процедура`    | Определение процедуры                    |
| `процедурабез` | Определение процедуры без параметров     |
| `печать`       | Вывод значения                           |
| `запомнить`    | Присваивание переменной                  |
| `вернуть`      | Возврат значения                         |
| `выполнить`    | Вызов процедуры                          |
